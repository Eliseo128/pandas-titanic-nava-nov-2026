## 🚀 ¿Cómo usar esta lista en clase?

1. **Asigna 1 ejemplo por equipo** (si tienes 30 estudiantes = 15 equipos)
2. Cada equipo adapta el código base del tutorial cambiando:
   - El nombre de las variables
   - La fórmula generadora de datos
   - Los títulos de las gráficas
3. **Presentación final:** cada equipo muestra su gráfica y explica qué predice su modelo
4. **Reto extra:** pedirles que agreguen una **segunda variable** (regresión múltiple)
